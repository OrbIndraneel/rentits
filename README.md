# RentIts

A modern rental marketplace platform built to simplify the process of listing, discovering, and renting products or services online.

---

## 🚀 Overview

**RentIts** is a full-stack rental platform that enables users to:

* List products/items for rent
* Browse available rentals
* Manage bookings and availability
* Connect renters with owners
* Handle authentication and user management
* Provide a smooth and responsive user experience

The project focuses on creating a scalable and user-friendly rental ecosystem with modern web technologies.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/OrbIndraneel/rentits.git
```

### 2. Navigate to the Project

```bash
cd rentits
```

### 3. Install Dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

## ▶️ Running the Project

### Development Mode

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm start
```

## 🔑 Environment Variables

Create a `.env` file in the root directory and add the required environment variables.

Example:

```env
PORT=3000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
API_KEY=your_api_key
```
